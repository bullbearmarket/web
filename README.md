# BullBear Market 🚀

## Overview
BullBear Market is a modern stock market learning and trading simulation platform designed for beginners and intermediate users.

## Features
- 📊 Trading UI & charts
- 🏆 Leaderboard system
- 📚 Learning section (beginner to advanced)
- ⚡ Fast and responsive design

## Tech Stack
- HTML
- CSS
- JavaScript

## Live Website
https://bullbearmarket.in

## Purpose
This project helps users understand stock market concepts like bull and bear trends, which represent rising and falling markets respectively.

## Future Plans
- Real-time data integration
- AI-based trading suggestions
- Mobile app version
